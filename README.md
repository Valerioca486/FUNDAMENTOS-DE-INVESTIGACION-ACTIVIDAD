## Cómo publicarla en GitHub Pages
1. Entra a github.com e inicia sesión.
2. Crea un repositorio **público** nuevo (por ejemplo `fundamentos-investigacion`).
3. Sube `index.html`, `README.md` y `.nojekyll` (Add file → Upload files) y pulsa *Commit changes*.
4. Ve a *Settings → Pages*. En *Build and deployment* elige *Deploy from a branch*, rama `main` y carpeta `/ (root)`, y guarda.
5. Espera uno o dos minutos. Tu enlace será `https://TU-USUARIO.github.io/fundamentos-investigacion/`.
